DEPLOY TO GITHUB / NETLIFY
--------------------------
1. Replace the existing index.html, styles.css, main.js, and logo.jpg in the GitHub repository with these four files.
2. Commit the changes.
3. Netlify should automatically redeploy from the connected GitHub repository.
4. Hard-refresh the site after deployment if the old CSS is cached.
